# 👑 Cielito de Flores VIP

## Colección Signature de Arreglos Florales Premium

Cielito de Flores VIP es un catálogo digital exclusivo diseñado para exhibir arreglos florales de lujo, ramos gigantes, colecciones Signature y diseños personalizados para clientes que buscan sorprender con experiencias inolvidables.

Nuestra plataforma permite explorar cada colección desde cualquier dispositivo móvil, descubrir diseños exclusivos, consultar precios y solicitar información o realizar pedidos directamente por WhatsApp.

El catálogo está optimizado para ofrecer una experiencia premium, elegante y rápida, disponible las 24 horas del día para brindar atención personalizada.

# 💎 Estructura de Productos

Cada producto incluye:

- Nombre
- SKU
- Precio
- Galería de imágenes
- Categoría
- Colección
- Descripción
- Etiquetas Premium
- Disponibilidad

Ejemplo:

```ts
{
  id: 1,
  title: "The Royal 300",
  sku: "VIP-001",
  price: 6500,
  collection: "Luxury Roses"
}
```
